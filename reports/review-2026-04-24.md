### Rationale
Core backend flows (login, artifacts CRUD, graph, chat) are functional and data is healthy (667 artifacts). However, P0 issues block production readiness: the ephemeral JWT secret invalidates all sessions on every restart, the graph search arity bug crashes the API on empty matches, the Neo4j driver leaks connections, and the blocking embedding call freezes the event loop. Neo4j is offline in the test environment, but the SQLite fallback works correctly. LightRAG is unconfigured but degrades gracefully. Frontend code shows good patterns (lazy loading, Suspense, mobile drawer) but has auth-guard and responsive gaps.
