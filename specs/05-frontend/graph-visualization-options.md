# 知识图谱可视化方案对比

## 问题陈述

知识图谱可视化面临的核心挑战：

1. **节点数量过多**：当节点超过 100 个时，D3.js 力导向图性能下降，交互卡顿
2. **信息密度过高**：全量展示时，节点和边过于密集，用户难以聚焦
3. **筛选需求多样**：用户可能需要按朝代、类别、人物等不同维度筛选
4. **路径发现需求**：需要支持"两个节点之间的最短路径"查询

本文档提供 3 套方案供选择。

---

## 方案对比总览

| 维度 | 方案 A：分页加载 | 方案 B：聚合视图 | 方案 C：混合方案 ⭐ 推荐 |
|------|-----------------|-----------------|------------------------|
| **核心思想** | 按度数/重要性分页 | 按类别/朝代聚合显示 | 动态聚合 + 按需展开 |
| **初始加载** | 只显示 Top 50 节点 | 显示聚合后的超级节点 | 显示核心节点 + 聚合标签 |
| **性能** | ⭐⭐⭐ 好 | ⭐⭐⭐⭐⭐ 极好 | ⭐⭐⭐⭐ 很好 |
| **交互复杂度** | ⭐⭐ 简单 | ⭐⭐⭐ 中等 | ⭐⭐⭐⭐ 较复杂 |
| **信息完整性** | ⭐⭐⭐ 中等 | ⭐⭐ 较低 | ⭐⭐⭐⭐ 较高 |
| **实现难度** | ⭐⭐ 简单 | ⭐⭐⭐ 中等 | ⭐⭐⭐⭐ 较难 |

## 方案 A：分页加载（Degree-based Pagination）

### 核心思想

按节点的度数（连接数）排序，只显示最重要的 N 个节点，提供翻页/加载更多功能。

│  ┌─────────────────────────────────────────────────────┐   │

│  │                    ● 故宫博物院                      │   │
│  │                   / | \                             │   │
│  │          唐代 ●--●  |  ●--● 青铜器                   │   │
│  │                |    |    |                          │   │
│  │                ● 金缕玉衣 ●                         │   │
│  │                |          |                         │   │
│  │          汉代 ●          ● 刘胜                     │   │
│  │                                                     │   │
│  │     （只显示度数最高的 50 个节点）                   │   │
│  │                                                     │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  显示: 50 / 1,247 节点    [加载更多]  [显示全部（可能卡顿）] │

### 技术实现

```javascript
// 后端：按度数排序分页查询
async function getTopNodes(limit = 50, offset = 0) {
  const query = `
    MATCH (n)
    OPTIONAL MATCH (n)-[r]-()
    WITH n, count(r) as degree
    ORDER BY degree DESC
    SKIP $offset LIMIT $limit
    RETURN n, degree
  `;
  return await neo4j.run(query, { offset, limit });
}

// 前端：无限滚动加载
function GraphVisualization() {
  const [nodes, setNodes] = useState([]);
  const [offset, setOffset] = useState(0);
  const [hasMore, setHasMore] = useState(true);
  
  const loadMore = async () => {
    const newNodes = await fetchTopNodes(50, offset);
    setNodes([...nodes, ...newNodes]);
    setOffset(offset + 50);
    setHasMore(newNodes.length === 50);
  };
  
  return (
    <>
      <ForceGraph nodes={nodes} />
      {hasMore && <Button onClick={loadMore}>加载更多</Button>}
    </>
  );
}
```

### 优缺点

- ✅ **优点**：
  - 实现简单，后端查询快速
  - 保证显示的都是重要节点
  - 用户体验直观
  
- ❌ **缺点**：
  - 可能遗漏重要但度数低的节点
  - 无法全局浏览图谱结构
  - 频繁加载可能打断探索流程

// 聚合查询
async function getClusteredNodes(groupBy = 'era') {
  const query = `
    MATCH (n:Artifact)
    WHERE n.${groupBy} IS NOT NULL
    WITH n.${groupBy} as group, collect(n) as nodes, count(n) as count
    RETURN group, count, 
           nodes[0..5] as sampleNodes  // 返回样本用于展示
  `;
  return await neo4j.run(query);
}

// 展开聚合节点
async function expandCluster(groupBy, groupValue, filters = {}) {
  const query = `
    MATCH (n:Artifact {${groupBy}: $groupValue})
    WHERE ${buildFilterCondition(filters)}
    RETURN n
    SKIP $offset LIMIT $limit
  `;
  return await neo4j.run(query, { groupValue, offset: 0, limit: 20 });
}

// 前端组件
function ClusteredGraph() {
  const [viewMode, setViewMode] = useState('cluster'); // 'cluster' | 'detail'
  const [clusterKey, setClusterKey] = useState('era');
  const [selectedCluster, setSelectedCluster] = useState(null);
  
  return viewMode === 'cluster' ? (
    <ClusterView 
      clusterKey={clusterKey}
      onClusterClick={cluster => {
        setSelectedCluster(cluster);
        setViewMode('detail');
      }}
    />
  ) : (
    <DetailView
      cluster={selectedCluster}
      onBack={() => setViewMode('cluster')}
    />
  );
}
```

## 方案 C：混合方案 - 动态聚合 + 鱼眼视图 ⭐ 推荐

### 核心思想

结合方案 A 和 B 的优点：
1. 初始显示核心节点（度数高）+ 周围聚合标签
2. 鼠标悬停/点击时，动态展开聚合显示详细节点
3. 使用"鱼眼视图"（Fisheye View）技术，聚焦区域放大，边缘区域压缩

// 动态聚合算法
function computeDynamicLayout(allNodes, centerNodeId, focusRadius = 200) {
  const centerNode = allNodes.find(n => n.id === centerNodeId);
  const focusedNodes = [];
  const clusteredNodes = [];
  
  allNodes.forEach(node => {
    const distance = computeDistance(node, centerNode);
    if (distance < focusRadius) {
      focusedNodes.push({ ...node, isFocused: true });
    } else {
      clusteredNodes.push(node);
    }
  });
  
  // 对非聚焦节点按属性聚合
  const clusters = groupBy(clusteredNodes, 'era');
  
  return {
    focusedNodes,
    clusters: Object.entries(clusters).map(([era, nodes]) => ({
      id: `cluster-${era}`,
      label: era,
      count: nodes.length,
      nodes,
      x: computeClusterCenter(nodes).x,
      y: computeClusterCenter(nodes).y,
      isCluster: true
    }))
  };
}

// 鱼眼视图实现（使用 D3.js fisheye 插件）
function FisheyeGraph({ nodes, links }) {
  const svgRef = useRef();
  
  useEffect(() => {
    const svg = d3.select(svgRef.current);
    const fisheye = d3.fisheye()
      .radius(150)
      .power(2);
    
    svg.on('mousemove', function(event) {
      const mouse = d3.pointer(event);
      fisheye.center(mouse);
      
      // 应用鱼眼变形到节点位置
      nodes.forEach(node => {
        const distorted = fisheye([node.x, node.y]);
        node.fx = distorted[0];
        node.fy = distorted[1];
      });
      
      simulation.alpha(0.1).restart();
    });
  }, []);
  
  return <svg ref={svgRef}>{/* ... */}</svg>;
}

// 交互：展开聚合节点
function handleClusterClick(cluster) {
  // 将聚合节点的子节点添加到视图中
  const expandedNodes = cluster.nodes.map(n => ({
    ...n,
    isExpanding: true,
    clusterParent: cluster.id
  }));
  
  setNodes([...nodes, ...expandedNodes]);
  // 重新计算布局
  simulation.nodes(nodes);
}
```

## 推荐决策

### 如果追求快速上线

**选择方案 A（分页加载）**
- 实现最简单
- 用户体验可接受
- 后续可平滑升级到方案 C

### 如果数据量极大（>10,000 节点）

**选择方案 B（聚合视图）**
- 性能最好
- 宏观视角有价值
- 适合博物馆管理者使用

### 如果追求最佳用户体验 ⭐

**选择方案 C（混合方案）**
- 兼顾性能和细节
- 现代图谱可视化标准做法
- 可逐步迭代优化
