# 项目概览

## 项目简介

文物数据仪表板是一个综合性的文物和文献管理分析平台，为文化遗产数字化提供完整的解决方案。通过集成数据采集、知识图谱构建和AI智能问答功能，帮助用户高效管理和挖掘文物数据价值。

## 核心功能

### 数据管理
- **文物信息管理**：支持文物基本信息、分类和描述的录入和管理
- **附件系统**：提供文件上传、存储和关联功能
- **批量导入导出**：通过Excel模板实现数据的批量操作

### 智能分析
- **知识图谱**：基于Neo4j构建文物关系网络，支持可视化展示
- **全文搜索**：提供高效的文物和文献检索功能
- **AI问答**：集成MCP插件，支持自然语言问答和智能推荐

### 可视化展示
- **数据统计**：提供各类数据统计图表和分析报告
- **词云分析**：通过词频分析展示热点内容
- **图谱可视化**：直观的知识图谱交互界面

## 技术架构

### 前端技术栈
- **React**：现代化的用户界面框架
- **Ant Design**：企业级UI组件库
- **响应式设计**：支持多种设备访问

### 后端技术栈
- **Node.js/Express**：高性能后端服务框架
- **RESTful API**：标准化的API设计
- **JWT认证**：安全的用户身份验证

### 数据存储
- **MySQL**：关系型数据存储，主数据表
- **Neo4j**：图数据库，知识图谱存储
- **Redis**：缓存服务，性能优化

### 辅助工具
- **Python脚本**：数据爬取和预处理
- **Docker容器化**：环境一致性和部署便捷
- **Swagger文档**：API接口文档自动生成
