### 4.1 目标文件分析

**文件**：`frontend/src/pages/KnowledgeGraph.js` (1453行)

**功能模块划分**：

| 行号范围 | 模块名称 | 职责 | 拆分优先级 |
|---------|---------|------|-----------|
| 1-100 | 状态初始化 | useState, useRef, 常量定义 | - |
| 100-300 | D3力导向模拟 | forceSimulation, forceManyBody等 | ⭐⭐⭐⭐⭐ |
| 300-500 | 图渲染逻辑 | SVG创建, 节点/边渲染 | ⭐⭐⭐⭐⭐ |
| 500-700 | 交互处理 | 高亮、钉住、缩放 | ⭐⭐⭐⭐ |
| 700-900 | 参数面板 | 力导向参数调节UI | ⭐⭐⭐ |
| 900-1100 | 实体详情 | 弹窗、属性展示 | ⭐⭐⭐ |
| 1100-1300 | 类型筛选 | 节点类型过滤 | ⭐⭐ |
| 1300-1453 | 布局 | Page布局, Sider, Content | ⭐ |

### 4.3 实施步骤

#### Step 1: 创建目录结构 (30分钟)

```bash
mkdir -p frontend/src/features/knowledge-graph/{components,hooks,utils}
touch frontend/src/features/knowledge-graph/index.js
```

#### Step 2: 提取Hooks

**useGraphSimulation.js** 提取要点：
- 从原文件复制forceSimulation初始化代码
- 提取nodes, links状态管理
- 提取updateForces函数
- 返回：{ simulation, nodes, links, updateForces }

**useGraphInteraction.js** 提取要点：
- 提取highlightNode, unhighlightNode
- 提取pinNode, unpinNode
- 提取focusNode
- 返回：{ highlightedNode, pinnedNodes, ...handlers }

#### Step 3: 提取组件

**GraphRenderer.js** 提取要点：
- Props接口：
  ```javascript
  {
    nodes: Array,
    links: Array,
    width: number,
    height: number,
    onNodeClick: Function,
    onNodeHover: Function,
    // ...
  }
  ```
- 使用useGraphSimulation和useGraphInteraction
- 渲染SVG和D3元素

#### Step 4: 重构页面

**KnowledgeGraph.js** 精简后结构：
```javascript

import { ForceSettingsPanel } from '../features/knowledge-graph';
// ...

  // 渲染组件
}
```
