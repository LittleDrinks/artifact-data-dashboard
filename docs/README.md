# docs/ 目录索引

本文档目录存放项目相关的所有文档资料。

## 目录结构

```
docs/
├── README.md                     # 本文件
├── PRD.md                        # 产品需求文档
├── architecture.md               # 系统架构文档
├── pitfalls.md                   # 踩坑记录
├── 背景调研.md                    # 项目背景调研
├── demo/                         # UI 原型（参考，勿修改）
└── specs/                        # 功能规格说明书
    └── modules/                  # 功能模块 spec
        ├── artifact-management.md
        ├── auth.md
        ├── dashboard.md
        ├── data-pipeline.md
        └── image-repair.md
```

## 各文件说明

| 文件 | 说明 |
|------|------|
| `PRD.md` | 产品需求文档 |
| `architecture.md` | 系统整体架构设计 |
| `pitfalls.md` | 开发过程中遇到的问题及解决方案 |
| `背景调研.md` | 项目立项前的背景调研资料 |
| `demo/` | UI 原型文件（HTML/CSS/截图），仅作参考，**请勿修改** |
| `specs/modules/` | 各功能模块的详细规格说明 |
