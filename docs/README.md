---

## 各目录说明

| 目录 | 用途 |
|------|------|
| `demo/` | UI 原型文件（HTML/CSS/截图），仅作参考，**请勿修改** |
| `report/` | 各类 code review、架构评审、安全审计、技术债务调查报告 |
| `specs/design/` | 系统设计层面的规格文档 |
| `specs/modules/` | 各功能模块的详细规格说明 |
| `specs/release/` | 发布前检查清单与优化事项 |
