## 1. 信息架构总览

### 1.1 架构原则

1. **以任务为中心**: 围绕"检索-探索-分析-产出"的研究流程组织信息
2. **渐进式披露**: 复杂功能分层展示，降低认知负担
3. **上下文感知**: 根据用户当前操作动态调整界面
4. **一致性**: 统一的导航、术语和交互模式

## 4. 内容分类

### 4.1 实体类型

| 实体类型 | 属性 | 图标 | 颜色 |
|----------|------|------|------|
| **文物** | 名称、年代、类别、材质、尺寸、收藏地 | 🏺 | #1890ff (蓝) |
| **人物** | 姓名、生卒年、身份、简介 | 👤 | #52c41a (绿) |
| **地点** | 名称、类型、地址 | 📍 | #faad14 (黄) |
| **朝代** | 名称、起止年份 | 👑 | #722ed1 (紫) |
| **类别** | 名称、父类别 | 🏷️ | #13c2c2 (青) |

### 4.2 关系类型

| 关系 | 方向 | 说明 | 示例 |
|------|------|------|------|
| **创作于** | 文物 → 人物 | 文物的创作者 | 青铜鼎 → 佚名 |
| **收藏于** | 文物 → 地点 | 文物的收藏机构 | 青铜鼎 → 故宫 |
| **属于** | 文物 → 朝代 | 文物的年代归属 | 青铜鼎 → 唐代 |
| **属于** | 文物 → 类别 | 文物的分类 | 青铜鼎 → 青铜器 |
| **生活在** | 人物 → 朝代 | 人物的生活年代 | 李白 → 唐代 |

### 4.3 内容层级

```
文物数据

    ├── 朝代
    ├── 类别
    ├── 材质
    └── 收藏地

Level 2: 图谱内搜索
├── 节点定位
├── 路径查找
└── 子图提取
```

### 5.2 搜索建议数据结构

```typescript
interface SearchSuggestion {
  type: 'history' | 'hot' | 'entity' | 'completion';
  value: string;
  entityType?: 'artifact' | 'person' | 'location';
  entityId?: string;
  highlight?: string;
}

// 示例
const suggestions: SearchSuggestion[] = [
  { type: 'history', value: '唐代青铜器' },
  { type: 'hot', value: '故宫博物院藏品' },
  { type: 'entity', value: '青铜龙纹鼎', entityType: 'artifact', entityId: 'art_001' },
  { type: 'completion', value: '唐代青铜器纹饰', highlight: '唐代青铜' },
];
```
