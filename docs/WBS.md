---

## 1. 项目概述

### 1.1 项目目标

将 Artifact Data Dashboard 从多页面架构迁移到**工作台为中心**的统一界面，实现：

- **单一入口**: 所有功能集中在 `/workbench` 页面完成
- **左右分栏**: 左侧文物探索区 + 右侧智能助手区
- **实时联动**: 选中文物自动触发AI关联问答
- **一键部署**: `docker-compose up` 启动完整系统

### 1.2 架构愿景

| **ResizableDivider** | 新建 | 可拖拽分隔线 | components/Workbench/Layout/ |

### 4.2 状态管理分层

```
Global State (Zustand/Redux)
├── layout: { leftMode, rightMode, leftWidth, rightWidth }
├── selection: { artifact, relatedArtifacts, graphNodes }
├── aiContext: { mode, toolsEnabled, conversationHistory }
└── inpaint: { sourceImage, repairedImage, repairType }

Local State (useState)
├── SearchPanel: { query, filters, results, loading }
├── GraphPanel: { nodes, links, zoom, selectedNode }
├── ChatPanel: { messages, input, streaming }
└── InpaintPanel: { uploadProgress, repairProgress }
```

## 7. 风险与应对

| 风险 | 可能性 | 影响 | 应对策略 |
|------|--------|------|----------|
| D3.js 性能瓶颈 | 中 | 高 | 准备 Canvas 混合渲染方案，限制节点数量 |
| 图像修复 API 不稳定 | 中 | 中 | 本地缓存 + 降级提示 |
| 状态管理复杂度过高 | 中 | 高 | 使用 Zustand 简化，避免过度设计 |
| 移动端适配工作量大 | 中 | 低 | 桌面端优先，移动端功能裁剪 |
| 旧代码迁移遗漏 | 中 | 中 | 建立迁移检查清单，代码审查 |
