## 1. 优先级 1：补齐验收标准缺口（上午 3h）

### 1.1 关联文物推荐（AC-2.4 增强）

**问题**：文物详情页是"死胡同"，没有引导用户继续探索的入口。

**User Story**：US-2.6（新增）：作为用户，我想要看到与当前文物相关的其他文物，以便继续探索。

**验收标准**：
- AC-2.6：详情页底部展示"相关文物"推荐（基于同年代/同类别/同地点，3-5 件）
- 推荐卡片可点击跳转到对应文物详情页

**实现方案**：

后端新增接口：
```
GET /api/artifacts/:id/related?limit=5
```
- 查询策略：同年代权重 3 + 同类别权重 2 + 同地点权重 1，取 top N
- 无关联文物时返回空数组

前端改动：
- `ArtifactDetail.tsx` 底部新增"相关文物"Section
- 使用 Ant Design Card 列表展示（缩略图 + 名称 + 年代）
- 点击跳转 `/artifacts/:id`

**关键文件**：
- `backend/app/routers/artifacts.py` — 新增 `/related` 端点
- `backend/app/services/artifact.py` — 新增 `get_related_artifacts()`
- `frontend/src/pages/ArtifactDetail.tsx` — 底部推荐区域

---

### 1.2 知识图谱一键聚焦

**问题**：全图 1362 个节点时，用户点击一个节点无法快速看清其邻居关系。

**User Story**：US-3.6（新增）：作为用户，我想要一键聚焦到某个节点及其邻居，以便排除干扰看清局部关系。

**验收标准**：
- AC-3.7：点击节点后详情面板增加"聚焦此节点"按钮
- 点击后隐藏所有无关节点，只保留目标节点及其直接邻居
- 提供"恢复全图"按钮回到原始状态

**实现方案**：

前端改动（纯前端，不需要后端改动）：
- 在详情面板添加"聚焦"按钮
- 过滤 D3 simulation 的 nodes/links 数据，只保留目标节点和直接相连节点
- 维护 `originalNodes`/`originalLinks` 备份用于恢复
- 聚焦时重新启动 simulation

**关键文件**：
- `frontend/src/pages/Graph.tsx` — 聚焦逻辑 + 恢复按钮

---

### 1.3 Dashboard 数据时间戳

**问题**：统计卡片没有时间维度，看不出数据是"活的"。

**User Story**：US-5.5（新增）：作为用户，我想要看到数据统计的时间戳，以便了解数据新鲜度。

**验收标准**：
- AC-5.5：统计卡片区域显示"数据截至 YYYY-MM-DD，共 N 件文物"

**实现方案**：

前端改动：
- 使用当前日期 + overview API 返回的 total_artifacts 拼接文案
- 显示在统计卡片行上方，灰色小字

**关键文件**：
- `frontend/src/pages/Dashboard.tsx`

---

### 1.4 图片 404 兜底

**问题**：部分文物 image_url 指向已失效的外部链接，显示破碎图标。

**验收标准**：
- AC-2.7（新增）：所有文物图片加载失败时显示统一的占位图
- 占位图使用 Ant Design `<Image fallback>` 或自定义 SVG 占位符
- 占位图风格与文化主题一致（建议：瓷器/青铜器轮廓简笔画 SVG）

**实现方案**：

前端改动：
- `ArtifactDetail.tsx` 和 `Artifacts.tsx` 的 Image 组件添加 `fallback` 属性
- 使用内联 SVG data URI 作为 fallback（无需额外文件）

**关键文件**：
- `frontend/src/pages/ArtifactDetail.tsx`
- `frontend/src/pages/Artifacts.tsx`

### 2.3 AI 服务不可用降级

**问题**：当 AI API Key 未配置或服务不可用时，Chat 页面报错不友好。

**验收标准**：
- Chat 页面检测到 AI 不可用时，在输入框上方显示黄色提示条
- 提示文案："AI 服务暂未配置，智能问答功能不可用。请联系管理员配置 AI_API_KEY。"
- 仍可查看历史会话和消息

**实现方案**：

后端新增健康检查：
```
GET /api/chat/health
```
- 检查 AI_API_KEY 是否配置
- 返回 `{available: true/false, reason: "..."}`

前端改动：
- Chat 页面初始化时调用 health 接口
- 不可用时显示 Alert 提示，禁用输入框

**关键文件**：
- `backend/app/routers/chat.py`
- `frontend/src/pages/Chat.tsx`

## 3. 优先级 3：防御性修复（下午后半 1h）

### 3.1 移动端基本可用

**问题**：侧边栏在窄屏下不可折叠，移动端体验差。

**验收标准**：
- 768px 以下屏幕侧边栏自动收起为图标模式
- 点击汉堡菜单可展开/收起

**实现方案**：

使用 Ant Design Layout.Sider 的 `breakpoint` + `collapsedWidth` 属性：

```tsx
<Sider
  breakpoint="lg"
  collapsedWidth={0}
  onBreakpoint={(broken) => setCollapsed(broken)}
>
```

**关键文件**：
- `frontend/src/layouts/AppLayout.tsx`

---

### 3.2 Chat AbortController 边界清理

**问题**：快速连续提问、切换会话时，可能有残留的 SSE 请求。

**验收标准**：
- 切换会话时 abort 上一请求
- 快速连续发送时只保留最新请求
- 组件卸载时 abort（如果用户离开 Chat 页面）

**关键文件**：
- `frontend/src/pages/Chat.tsx`

## 5. 不做的事

以下改动 1 天做不完或做了反而减分，**不纳入本次计划**：

- 3D 查看 / AR/VR — 工程量大，半成品减分
- 国际化 — 不影响答辩
- 推荐算法 / 语义搜索 — 需要 ML pipeline，1 天做不完
- 数据扩充 — 需要人工审核数据质量
- PWA / 离线访问 — 过度工程
- FTS5 全文检索 — 当前 771 条数据 ILIKE 足够
