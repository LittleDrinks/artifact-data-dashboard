## 1. 需求概述

Dashboard 是系统的首页入口，展示文物数据的统计概览，为用户提供数据全貌的直观视图。

### 1.1 页面

| 页面 | 路由 | 说明 |
|------|------|------|
| Dashboard | `/` | 统计卡片 + 柱状图 + 饼图 + 词云 |

### 1.2 业务需求

| 需求 | 描述 | 优先级 |
|------|------|--------|
| 统计概览 | 文物总数、分类统计 | P0 |
| 年代分布 | 柱状图展示各朝代文物数量 | P0 |
| 类别分布 | 饼图展示文物类别占比 | P0 |
| 词云展示 | 基于文物描述的词云 | P1 |

---

## 2. API 接口

### 2.1 端点列表

| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/stats/overview` | GET | 统计概览（总数、分类统计） |
| `/api/stats/by-era` | GET | 按朝代统计文物数量 |
| `/api/stats/by-category` | GET | 按类别统计文物数量 |
| `/api/stats/by-location` | GET | 按出土地点统计 |
| `/api/stats/wordcloud` | GET | 词云数据（jieba 分词） |

### 2.2 响应格式

**Overview**：
```json
{
  "total_artifacts": 771,
  "categories": [
    {"category": "青铜器", "count": 100},
    {"category": "陶瓷", "count": 50}
  ]
}
```

**by-era**：
```json
[
  {"era": "商", "count": 50},
  {"era": "唐", "count": 30},
  {"era": "宋", "count": 40}
]
```

**wordcloud**：
```json
[
  {"word": "青铜", "frequency": 100},
  {"word": "纹饰", "frequency": 80}
]
```

### 4.2 停用词列表（已扩展）

停用词表包含以下类别（`stats.py:21-53`）：

| 类别 | 示例 |
|------|------|
| 通用虚词 | 的、了、在、是、我、有、和、就、不 |
| 文物领域无意义词 | 一种、年代、时期、时代、世纪、前后、左右、目前、已知、现存、发现、出土 |
| 度量单位 | 厘米、毫米、米、公分、尺、寸、高度、长度、直径 |
| 通用动词 | 使用、利用、制作、雕刻、铸造、烧制、绘制、成为 |
| Wiki/法律术语 | 引用、参考、来源、注释、条例、发布、公布、列为 |
| 博物馆展示相关 | 博物馆、博物院、展览、国家一级 |
| 批次编号 | 第一批、第二批、第三批 |
| 通用描述词 | 位于、又称、称为、认为、可能、所有、之一、一件、年间 |

### 4.3 分词策略

- 使用 jieba 分词（精确模式）
- 过滤停用词、长度 < 2 的词、纯数字
- 要求至少包含一个汉字（过滤标点和英文）
- Tags 字段按逗号/顿号分隔，直接作为词项
