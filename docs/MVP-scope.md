# MVP 规格说明（一页纸）

> **最后更新：2026-04-13**
> 详细决策推理见 `architecture-decisions.md`

---

## 技术栈

| 层 | 选型 |
|----|------|
| 前端 | Vite + React + TypeScript + Ant Design Pro |
| 后端 | Python FastAPI（单服务） |
| 关系库 | SQLite（SQLAlchemy ORM，可升级 PostgreSQL） |
| 图数据库 | Neo4j Community |
| AI 引擎 | LangChain Agent + LightRAG |
| 图像修复 | IOPaint + LaMa |
| 部署 | Docker Compose（3 容器） |

---

## MVP 功能清单（7 个模块）

### P0 — 核心差异化能力

| # | 模块 | 页面 | 关键能力 |
|---|------|------|----------|
| 1 | **文物管理** | 列表页 + 详情页 | 搜索（全文+筛选）、CRUD、附件展示 |
| 2 | **知识图谱** | 图谱页 | D3.js 力导向图、节点点击查看关联、Neo4j 驱动 |
| 3 | **AI 智能问答** | 问答页 | LangChain Agent 编排、LightRAG 语义检索、SSE 流式输出 |

### P1 — 完整性必需

| # | 模块 | 页面 | 关键能力 |
|---|------|------|----------|
| 4 | **统计面板** | Dashboard 页 | 文物数量统计（按朝代/类型/馆藏）、图表可视化 |
| 5 | **附件管理** | 详情页内嵌 | 图片上传、画廊展示、附件元数据 |
| 6 | **图像修复插件** | 详情页内嵌 | IOPaint 遮罩绘制、前后对比、可扩展插件架构演示 |
| 7 | **用户认证** | 登录页 | JWT 登录、admin/viewer 两级角色 |

---

## 不做（后续扩展）

- 3D 模型预览、视频/音频管理
- OCR 文字识别
- 复杂权限（多角色/审批流）
- 元数据标准（Dublin Core / CDWA）
- 数据批量导入/导出 UI
- 通知系统、审计日志

---

## 页面清单（6 个）

```
/                  → Dashboard（统计面板）
/artifacts         → 文物列表（搜索 + 筛选）
/artifacts/:id     → 文物详情（元数据 + 图片画廊 + 图像修复）
/graph             → 知识图谱可视化
/chat              → AI 智能问答
/login             → 登录
```

## 开发排期（12 天 + 2 天缓冲）

```
Day 1-2   项目脚手架（Vite + FastAPI + SQLite + Neo4j + Docker）
Day 3-4   数据导入 + 文物 CRUD + 列表页/详情页
Day 5     统计面板（Dashboard）
Day 6-7   知识图谱可视化（Neo4j + D3.js）
Day 8-9   LightRAG 索引 + AI 问答 API + 问答页
Day 10    附件上传 + 图片画廊
Day 11    IOPaint 集成 + 图像修复 UI
Day 12    用户认证 + 全流程联调
Day 13-14 缓冲 / 修复 / 打磨
```

---

## 答辩演示路径（5 分钟）

```
1. Dashboard → 展示文物数据全貌（数量分布、朝代分布图表）
2. 文物列表 → 搜索"后母戊鼎" → 进入详情页（元数据 + 图片）
3. 知识图谱 → 点击节点 → 展开关联文物（同批出土、同时代）
4. AI 问答 → "商代青铜器有哪些典型纹饰？" → SSE 流式回答
5. 图像修复 → 绘制遮罩 → 修复对比 → 强调插件可扩展架构
```

---

## 数据目标

| 指标 | 目标 |
|------|------|
| 文物总数 | 500+ 条 |
| 有效正文（>=500 字） | 200+ 条 |
| 数据源 | Wikipedia（描述文本）+ Wikidata（结构化属性） |
| 重点覆盖 | 禁止出境展览文物 195 件 + 青铜器/瓷器/玉器分类 |
