<objective>
Fix knowledge graph D3 simulation restarting on every mouse hover.

Purpose: The D3 simulation `useEffect` depends on `drawCanvas`, which depends on `hoveredNode`. When the user hovers over a node, `hoveredNode` changes -> `drawCanvas` is recreated -> D3 effect re-runs -> new simulation with `alpha=1` starts, causing nodes to fly in from random positions (appearing to "reload"). Additionally, the cleanup function only calls `simulation.stop()` but never removes canvas event listeners, causing them to accumulate.
Output: D3 simulation effect no longer re-runs on hover; canvas event listeners are properly cleaned up; tooltip rendering is decoupled from simulation lifecycle.
</objective>
